# LAS-Survey

LAS 점군 보기 · 3D 돌려보기 · 타점 추출 · 횡단 · 종횡단 · 지형/GIS · 도로/하천/풍력 설계 프로그램 (Windows 10/11, 64비트)

## 설치
[최신 버전 받기](https://github.com/sjmmsjmm870-dev/las-survey/releases/latest) → `LAS-Survey_Setup_<버전>.exe` 를 받아 실행하세요 (관리자 권한 필요 없음).

- 처음 실행한 날부터 **7일 동안 모든 기능**을 쓸 수 있습니다.
- 그 뒤에는 라이선스 키가 필요합니다 (**키 하나에 PC 1대**, 처음 인증 때 인터넷 연결).
- 새 버전은 프로그램이 켤 때 알려 주며 [정보 ▾ 업데이트 확인]으로도 받을 수 있습니다.
